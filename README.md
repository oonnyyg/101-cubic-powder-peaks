# 理想立方晶胞粉末衍射峰计算

计算理想立方晶胞的粉末衍射峰位置与相对强度，仅依赖 Python 标准库。

## 用法

```
python -m powder_peaks 输入.json --out 输出目录
```

输出：

- `reflections.csv`：全部保留的反射（含零强度消光反射，供核查），
  列为 `h,k,l,q,d,two_theta_deg,intensity`，按 q 递增。
- `peaks.json`：按 q 合并后的峰表（排除总强度为零的峰），
  含 `q, d, two_theta_deg, intensity, relative_intensity, n_reflections`。

非法输入直接报错退出（退出码 1），且不写任何报告文件。

## 输入格式

```json
{
  "a": 4.0,
  "wavelength": 1.5406,
  "Q": 20,
  "atoms": [
    {"position": [0, 0, 0], "amplitude": 1.0, "occupancy": 1.0},
    {"position": [0.5, 0.5, 0.5], "amplitude": 1.0, "occupancy": 1.0}
  ]
}
```

- `a` 与 `wavelength`：正有限实数，单位相同。
- `Q`：正整数，1 ≤ Q ≤ 400，枚举所有满足 0 < h²+k²+l² ≤ Q 的有符号
  整数三元组（不约分互为倍数的指数，负指数与排列全部保留）。
- `atoms`：非空列表；分数坐标各在 [0,1)，振幅为正有限实数且与角度
  无关，占位率在 (0,1]。

## 公式

令 q = h² + k² + l²：

- 晶面间距：d = a / √q
- 仅保留 λ/(2d) ≤ 1 的反射；衍射角 2θ = 2·arcsin(λ/(2d))（输出为度）
- 结构因子：F(hkl) = Σⱼ occⱼ · fⱼ · exp(2πi(hxⱼ + kyⱼ + lzⱼ))
- 单反射强度 I = |F|²；若 I ≤ 1e-12·(Σⱼ occⱼ·fⱼ)² 则置零
- 同一 q 的所有反射（含负指数与全部排列）强度相加得到峰强度；
  峰表排除总强度为零的峰，最强峰归一为 100；强度不作其他修正。

## 峰的增强与消光

- **多重性增强**：立方晶系中同一 q 对应大量对称等效的 (hkl)
  （如 q=1 有 ±(100)、±(010)、±(001) 共 6 条），粉末样中这些反射
  角度完全相同，强度叠加，使峰按多重性增强。
- **系统消光**：晶胞内多个原子的散射波相位相互抵消时 F = 0。
  例如体心（原点 + (½,½,½) 同种原子）时
  F = f·(1 + e^{πi(h+k+l)})，h+k+l 为奇数时消光；
  面心时 h、k、l 奇偶混杂的反射消光。
- **部分抵消**：不同振幅原子（如 NaCl 型）使某些峰减弱而不完全消光，
  表现为强弱交替。
