# cubic-powder-peaks

计算理想立方晶胞的粉末衍射峰位置和相对强度，仅依赖 Python 标准库。

## 用法

```
python -m powder_peaks 输入.json --out 输出目录
```

输出两个文件：

- `reflections.csv`：全部保留反射（含零强度反射，供核查消光），列为
  `h,k,l,q,d,two_theta_deg,intensity`。
- `peaks.json`：按 `q = h²+k²+l²` 合并后的峰表，排除总强度为零的峰，
  含 `q, d, two_theta_deg, intensity, relative_intensity, reflection_count,
  extinct_count`，按 q 递增，最强峰归一为 100；无峰时为空表。

输入非法时以非零码退出且不写任何报告。

## 输入格式

```json
{
  "a": 4.05,
  "wavelength": 1.5406,
  "Q": 30,
  "atoms": [
    {"x": 0.0, "y": 0.0, "z": 0.0, "amplitude": 13.0, "occupancy": 1.0}
  ]
}
```

- `a`：晶格边长，正有限数；`wavelength`：波长 λ，正有限数，与 a 单位相同。
- `Q`：正整数，1 ≤ Q ≤ 400，枚举上界。
- `atoms`：非空列表；分数坐标 `x,y,z ∈ [0,1)`，`amplitude` 为有限正实数
  （与角度无关），`occupancy ∈ (0,1]`，所有数值必须有限。

## 公式

**反射枚举**：对所有有符号整数三元组 (h,k,l)，保留
`0 < q = h²+k²+l² ≤ Q`。互为倍数的指数（如 (100) 与 (200)）不约分，
各自独立成反射。

**晶面间距与衍射角**（立方晶系）：

```
d = a / √q
2θ = 2·arcsin(λ / 2d)        （布拉格定律，结果转为度）
```

仅保留 `λ/(2d) ≤ 1` 的反射。

**结构因子**：

```
F(hkl) = Σ_j occ_j · f_j · exp(2πi (h x_j + k y_j + l z_j))
```

单反射强度 `I = |F|²`。若 `I ≤ 1e-12 · (Σ_j occ_j·f_j)²`，视为消光并置零
（反射仍保留在 CSV 中）。

**峰合并**：相同 q 的反射（含全部负指数与排列）强度直接累加为一个峰，
不合并结构因子 F。峰表排除总强度为零的峰，相对强度按最强峰归一为 100。
强度不作洛伦兹、偏振等额外修正。

## 峰的增强与消光

- **增强（多重性）**：立方晶系中同一 q 对应多个对称等效的 (hkl) 组合
  （如 q=1 有 6 条 (100) 类反射，q=2 有 12 条 (110) 类），粉末样品的晶粒
  随机取向使这些反射在同一 2θ 处叠加，峰强度 = 各反射强度之和，因此高
  多重性的峰更强。
- **消光（系统消光）**：当晶胞内多个原子的散射波相位相互抵消时 F≈0。
  例如体心格子（原点 + (½,½,½) 同种原子）在 h+k+l 为奇数时
  `exp(πi(h+k+l)) = -1`，两项相消，(100)、(111) 等反射消失；面心格子
  在 h,k,l 奇偶混杂时消光。占位率或振幅不同的原子只能部分抵消，
  表现为强度减弱而非完全消光。
